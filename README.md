# CampAIsel
A student project exploring AI-assisted learning and related ideas.
CampAIsel — AI Learning Assistant

About the Project

CampAIsel is a planned Android mobile application designed to support students in their learning journey. It aims to provide access to learning resources, an AI-powered chatbot for educational questions, and a user profile for a personalized learning experience.

The project is currently in the idea and design stage. Features will be implemented and tested progressively.

Objectives

- Make learning resources easier for students to access.
- Design an interface for asking educational questions through an AI chatbot.
- Provide user registration, login, and profile management.
- Develop practical skills in mobile app development.
- Learn how to use Git and GitHub for project version control.

Planned Features

- Learning Resources: Browse study materials, notes, tutorials, and useful learning links.
- AI Chatbot: Ask educational questions and receive AI-generated explanations after an AI service is integrated.
- User Authentication: Register, log in, and sign out securely.
- User Profile: View and manage basic account information.
- Mobile-Friendly Interface: Design screens suitable for Android phones.

These features are planned and should not be considered implemented until they have been developed and tested.
